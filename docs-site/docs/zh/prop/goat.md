# 构象搜索（GOAT）

对于柔性分子，识别低能构象空间（conformational space）非常重要，这样才能为所研究的体系提供最精确的模型。ORCA 中的全局优化算法（global optimizer algorithm，GOAT）可以帮助自动找到全局最小值结构及其周围的系综。通过简单的输入关键词 `GOAT` 即可调用：

```text
!GOAT XTB

*XYZFILE 0 1 inp.xyz
```

> **注意**
> 由于一次 GOAT 运行涉及大量几何优化，建议并行化计算，例如使用 `PAL4` 关键词。此外，尤其对于大体系，使用 GFN2-xTB 这类快速半经验（semiempirical）方法可以加快计算。当然，GOAT 可以与 ORCA 中任何能够优化几何的方法配合使用。

输入如下：

```text
!GOAT XTB

*XYZFILE 0 1 diclofenac.xyz
```
