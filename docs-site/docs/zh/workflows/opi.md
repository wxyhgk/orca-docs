# ORCA Python 接口（OPI）

随着 ORCA 6.1 的发布，我们推出了由 FACCTs 支持的开源 ORCA Python 接口（ORCA Python Interface，OPI）。它可以在 [GitHub](https://github.com/faccts/opi) 上获取，也可以通过 [PyPI](https://pypi.org/project/orca-pi/) 安装。

[![opi_logo_horizontal](../images/opi_logo_horizontal.svg)](../images/opi_logo_horizontal.svg)

技术文档、指南和教程可在 [OPI 文档页面](https://www.faccts.de/docs/opi/1.0/docs/)找到。

> **技巧**
> OPI 是一个开源社区项目，因此非常欢迎外部开发者做出贡献。
