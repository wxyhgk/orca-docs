# 用于过渡态的多尺度 NEB-TS

现在让我们进一步探索多尺度（multilevel）方法的高级用法，并将其与 ORCA 的另一个重要特性结合起来：用于自动寻找过渡态（transition states）的 NEB-TS 方法。如果你还不了解 NEB-TS，请先查看上一篇教程"[用 NEB-TS 寻找过渡态](../react/nebts.md#nebts)"，从现在起我们将假定你已经理解它。

在本教程中，我们将使用常规 r^2SCAN-3c 与 XTB 的混合来寻找过渡态**并**计算其能垒。为了让事情不那么简单、也更有趣一些：我们的目标反应是下面所示的 Diels-Alder 反应：

[![reaction1](../images/reaction1.png)](../images/reaction1.png)

r2SCAN-3c 是 Stefan Grimme 课题组最近开发的另一种"3c"方法，它基于 meta-GGA 泛函 r^2SCAN，已经实现在 ORCA 中，并表现出非常优秀的基准测试结果 [[Grimme2021]](../bib.md#grimme2021)。

## 为 NEB-TS 计算准备输入文件

为了运行 NEB-TS，我们需要反应物和产物，最好已经用某种方法优化过。可以直接采用本页末尾的结构，并用以下方式优化：

```text
!R2SCAN-3C OPT FREQ
* XYZ 0 1
```

它们应该会在几步后收敛。在这里，使用 !PAL16 时，每个体系的完整优化加频率计算只花了大约 25 分钟。

这样我们就有了排布为反应物（educt）的反应体系以及产物。如前所述，成功进行 ONIOM 计算的第一个挑战是 QM1 和 QM2 区域的选择。由于我们的反应发生在二烯（diene）和亲双烯体（dienophile）之间，把两者都包含在较高水平的 r^2SCAN-3c 区域中是合理的。下面是一张 3D 图像，显示了其中一个分子的 ORCA 原子编号：

[![split](../images/split.png)](../images/split.png)

请注意，这里我们还把与乙烯基团相连的酯类吸电子基团也包含在内。它们之间有很强的电子关联，在这种情况下把它从主 QM1 区域中移除并不是明智之举。

## 用 ONIOM 运行 NEB-TS

NEB-TS 的 ORCA 输入一如既往地简单，只是必须显式指定 *%QMATOMS*：

```text
!QM/XTB R2SCAN-3C NEB-TS NUMFREQ
%QMMM QMATOMS {0:6 8 22:31} END END
%NEB PREOPT TRUE PRODUCT "product.xyz" END
* XYZFILE 0 1 reactant.xyz
```

这里有一些重要的说明：

> 1. 我们必须使用 NUMFREQ，因为 ORCA 中的 ONIOM 方法目前还没有解析 Hessian，而我们想在最后计算频率以确认确实找到了过渡态。
> 2. 我们的反应物/产物结构是用纯 r^2SCAN-3c 优化的。由于现在使用的是 ONIOM（它代表不同的势能面），在 NEB 之前对这些结构重新优化是合理的，因此我们设置 *PREOPT TRUE*。

完整的计算使用 !PAL8，包括数值频率计算在内只花了约 1 小时 20 分钟——对于这样一次从寻找过渡态一直到计算频率的完整计算来说，速度快得令人印象深刻。最终找到的过渡态只有一个虚频，为 $-358.36$ $cm^{-1}$。

## 与完整 DFT 结果的比较

我们也可以将 ONIOM 结果与完整 DFT 结果进行比较，以作检查：

```text
!R2SCAN-3C NEB-TS FREQ
%NEB PRODUCT "product.xyz" END
* XYZFILE 0 1 reactant.xyz
```

NEB 收敛后找到了过渡态，能垒为 $E_{barrier}^{ONIOM}=10.25$ $kcal/mol$。这意味着在这个例子中，我们的 ONIOM 相对于完整计算只有 10% 的误差。

取这些 ONIOM 结构并重新计算 DFT 能量，得到的能垒为 $E_{barrier}^{DFT/ONIOM}=10.63$ $kcal/mol$，与精确结果相当接近。

将所找到的两个过渡态结构叠合在一起也表明，结果非常相似：

[![overlay](../images/overlay.png)](../images/overlay.png)

作为本节的总结，过渡态的完整 DFT 频率为 $-370.80$ $cm^{-1}$，也与之前用多尺度方法得到的结果一致。

## 一个来自文献的大体系例子

为了展示多尺度方法在非常大的体系上的表现，让我们以 Frank Neese 教授课题组与 Benjamin List 教授（2022 年诺贝尔化学奖得主！）课题组合作的一篇近期论文为例。

List 教授的课题组以其使用有机分子作为催化剂的反应而闻名，其中一种反应就是下面这个立体选择性 Diels-Alder 反应 [[Bistoni2020]](../bib.md#bistoni2020)：

[![list](../images/list.png)](../images/list.png)

该文献非常详细地描述了用 DFT 和 DLPNO-CCSD(T) 研究这个反应的工作。我们**不**打算复现其中的任何结果，而只是展示如何将 NEB-TS 与 ORCA 的 ONIOM 结合使用，来寻找这个 206 个原子的大体系的过渡态。

一如既往，NEB-TS 需要反应物和产物。这些结构由原作者友情提供，已经过预优化，起始结构打印在本页末尾。

### 设置更复杂的输入——电荷

现在我们可以运行 NEB-TS 计算来寻找该反应涉及的过渡态。采用 QM/XTB 方法并以 PBE/def2-SVP 作为 QM 方法，输入文件如下：

```text
! QM/XTB PBE D3BJ def2-SVP NEB-TS NUMFREQ
%NEB
 product "product.xyz"
 preopt true
END
%QMMM
 QMAtoms { 151:205 } end
 Charge_Total 0
END
* XYZFILE 1 1 reactant.xyz
```

这对应于下图所示的区域划分，其中实心球代表较高水平的 DFT 区域：

[![rot](../images/rot.gif)](../images/rot.gif)

这里有几个要点：

> 1. 我们把 !NEB-TS 与 `!NUMFREQ?` 一起使用，以便在最后计算频率来验证过渡态。请记住，ORCA 目前只能对多尺度计算进行数值频率计算。
> 2. 建议使用 `PREOPT TRUE`，以便对反应物和产物进行预优化，因为它们之前是用另一种方法优化的。

请注意，现在在 *QMAtoms* 之后还有 *Charge_Total 0*。这是**整个体系（QM1 + QM2，即 DFT + XTB）**的电荷，在本例中是中性的。在上面的 Lewis 结构式中可以看到，反应物实际上是一个阳离子，而催化剂是一个阴离子。

总电荷为零，然而由于我们选择了反应物（educt）作为较高水平的 QM 区域，输入文件末尾在 *xyzfile* 之后给出的电荷必须是 +1。在那里必须给出**较高水平 QM 体系的总电荷**，而较低水平 XTB 的电荷将由此值与 *Charge_Total* 推导得出。

> **重要**
> 与多重度一起写在坐标段中的电荷，**始终是最高水平区域的电荷**。多重度也是如此：它可以通过 *%QMMM* 下的 *Mult_Total* 为整个体系设置，同时也必须为较高水平的体系设置。

> **注意**
> 如果没有给出 *Charge_Total* 或 *Mult_Total*，则假定为一个所有电子都配对的中性体系。

使用 !PAL16（16 个核心）时，这次计算花了 15 个小时，只找到一个虚频，为 $-384.94$ $cm^{-1}$。NEB-TS 的总体结果如下：

### 减小活性区域的大小

从上面的 MEP 可以看出，实际上大部分变化都发生在非常靠近反应物（educt）的位置。这在预期之中，因为在这种情况下催化剂的作用只是把反应物拉到一起并正确定位。我们可以在近似上再进一步，限制这次优化的*活性区域（Active Region）*。

这里我们所说的*活性区域*，是指分子/体系中实际移动并被优化的部分。对于具有局域键断裂/形成的较大体系，在几何优化中我们基本上可以忽略周围环境，只把中心相关的部分纳入 NEB-TS。

为此，需要使用如下输入：

```text
! QM/XTB PBE D3BJ def2-SVP NEB-TS NUMFREQ
%NEB
 product "product.xyz"
 preopt true
END
%QMMM
 QMAtoms { 151:205 } end
 ActiveAtoms {151:205} end
 Charge_Total 0
END
* XYZFILE 1 1 reactant.xyz
```

这基本上与之前相同，只是现在还有一个 *ActiveAtoms* 列表。在这个例子中，我们选择它与较高水平的 DFT 区域一致，但原则上它可以是任意的。现在再看 QMMM 输出的最后一部分：

```text
Size of region for optimizer           ... 59
        optimized atoms = activeRegion ... 55
        fixed atoms (distance cutoff)  ... 4 ( 1.0)
Composition of different systems (atoms start counting at 0):
QM1 Subsystem                          ... 151 152 153 154 155 156 157 158 159 160
                                           161 162 163 164 165 166 167 168 169 170
                                           171 172 173 174 175 176 177 178 179 180
                                           181 182 183 184 185 186 187 188 189 190
                                           191 192 193 194 195 196 197 198 199 200

```

可以看到，*Active atoms* 的数目与我们所选择的一致，但优化器中还会加入另外 4 个 *Fixed atoms*。这些原子是根据它们与活性原子的距离选出的，对稳定几何优化很重要。它们只是笛卡尔坐标被完全固定的原子。

原则上，这四个额外的原子不会带来太大差别（在某些情况下可能会多得多），但它们对于避免 *Active atoms* 移动到被忽略原子所在的空间区域确实是必要的。不需要对这些设置做额外调整，但更多信息可以在 [ORCA 手册](https://www.faccts.de/docs/orca/6.0/manual)中找到。
