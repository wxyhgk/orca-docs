# Hello water！你的第一个 ORCA 计算

在[正确安装 ORCA](#sec:installation) 之后，您就可以用 ORCA 进行第一次计算了！这里我们将以计算水分子的能量为例，使用 [Hartree-Fock 理论](#sec:essentialelements.hartreefock)和 def2-SVP [基组（basis set）](#sec:essentialelements.basisset)。我们将使用如下 `hellowater.inp` ORCA 输入文件：

```mol
title: structure 1
theme: chem311
height: 320px
representation: ball-stick
--- xyz ---
3
structure (0 1)
O        0.0000       0.0000       0.0626
H       -0.7920       0.0000      -0.4973
H        0.7920       0.0000      -0.4973
--- input ---
! HF DEF2-SVP

* XYZ 0 1
O   0.0000   0.0000   0.0626
H  -0.7920   0.0000  -0.4973
H   0.7920   0.0000  -0.4973
*
```

!!! tip
    输入文件通常使用 `.inp` 扩展名，但 `.txt` 也可以。

现在您可以运行 ORCA 了。

```orca
orca hellowater.inp > hellowater.out
```

输出随后会打印到工作目录中的文件 `hellowater.out` 里。

然后您可以打开输出文件查看计算结果（注意在计算运行期间不要覆盖它）。如果计算正常结束，输出文件末尾会打印相应消息。

```orca
                             ****ORCA TERMINATED NORMALLY****
```

水分子的能量现在可以在输出文件中找到：

```orca
-------------------------   --------------------
FINAL SINGLE POINT ENERGY       -75.959340303174
-------------------------   --------------------
```

恭喜，您已成功用 ORCA 完成了第一次量子化学计算！
