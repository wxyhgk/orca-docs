# 通过 RPA、CIS、TD-DFT 和 SF-TDA 计算激发态（Excited States via RPA, CIS, TD-DFT and SF-TDA）

ORCA 提供了一个相对高效的单激发组态相互作用（CIS）模块、
"无规相位近似"（random-phase approximation, RPA）以及含时密度泛函理论（TD-DFT）模块，
可用于计算激发能、吸收强度和圆二色（CD）强度。
其中 TD-DFT 在激发态计算中尤为流行，因为它在几乎相同的计算代价下
给出明显优于 HF-CIS 的结果。然而，TD-DFT 也存在许多陷阱，
其中一些已在综述中讨论
[neese2006jbiolinorgchem](../../bibliography.md)[neese2009coordchemreviews](../../bibliography.md)。TD-DFT 方法
可用于闭壳层和自旋非限制性参考态，并带有共线自旋翻转（spin-flip）变体。
所有这些情形都提供解析梯度。此外还实现了双激发校正，
可改善结果（但也会增加计算量）。它常与双杂化泛函一起使用，如下文所述。
ORCA 的 TD-DFT 模块也广泛用于计算给定元素 K 边的 X 射线吸收谱。

从 6.0.0 版本开始，吸收波长、振子强度等的输出格式与 5.0.x 版本相比
发生了变化。关于输出解读的更多细节，请参见 [spectroscopyproperties.ops](#sec:spectroscopyproperties.ops)。

<a id="sec:spectroscopyproperties.tddft.general"></a>
## 一般特性（General Features）

该模块通过以下输入块调用：

```orca
%cis  end

# or equivalently

%tddft end
```

有多种选项可供选择。其中最重要的是需要计算的激发态数目：

```orca
%cis NRoots    10  end
```

收敛阈值由以下参数给出：

```orca
%cis
  ...
  ETol  1e-6
  RTol  1e-6
end
```

变量 `ETol` 给出激发态能量（以 Eh 为单位）所要求的收敛精度，
而 `RTol` 是残差向量范数所要求的收敛精度。在正常情况下，
计算大约需要 5–10 次迭代即可收敛到默认的收敛阈值。

收敛后，程序会打印波函数组成。为使输出简洁，
小于 0.01 的系数将被省略。该阈值可通过关键词 `TPrint` 调整。

```orca
%cis 
  ...
  TPrint 0.0001 # cut-off for the wave function printing, default= 0.01
end
```

若使用闭壳层参考态，程序可以通过以下设置同时计算单重态和
自旋适配的三重激发态：

```orca
%cis 
  ...
  triplets  true
end
```

该选项适用于所有方法组合，包括解析梯度，也适用于双杂化泛函。

为控制计算中需要考虑的轨道，有两种机制可用。第一种是默认机制，
即指定一个轨道能窗口，窗口内的所有单激发都将被考虑：

```orca
%cis 
  ...
  EWin  -3,3  # (orbital energy window in Eh)
end
```

因此，默认做法是冻结核心轨道并忽略能量很高的虚轨道，这是一个合理的近似。
不过，您也可以通过例如选择 `EWin -3,10000` 来包含所有虚轨道。
第二种机制是为每个算符显式给出轨道能窗口，即

```orca
%cis
  ...
  OrbWin[0] = 2,-1,-1,14 # orbital window for spin-up MOs
  OrbWin[1] = 2,-1,-1,16 # orbital window for spin-down MOs
end
```

上例中的 "-1" 表示自旋向上和自旋向下轨道的 HOMO 与 LUMO 将由
程序自动确定。换言之，在上例中，TDDFT 计算只包含以下激发：

-   从任意占据的 alpha 轨道（其指标在 2（含）与 alpha HOMO（含）之间）
    到任意虚 alpha 轨道（其指标在 alpha LUMO（含）与 14（含）之间）的激发

-   从任意占据的 beta 轨道（其指标在 2（含）与 beta HOMO（含）之间）
    到任意虚 beta 轨道（其指标在 beta LUMO（含）与 16（含）之间）的激发

对于基于限制性参考态的计算，`OrbWin[1]` 将被忽略。

在使用 CIS/TD-DFT 模块时，应区分五种不同类型的计算：

-   半经验方法

-   Hartree-Fock 计算

-   无 HF 交换的 DFT 计算（非杂化泛函）

-   含 HF 交换的 DFT 计算（杂化泛函）

-   含 HF 交换和 MP2 相关的 DFT 计算（双杂化泛函）

<a id="sec:spectroscopyproperties.tddft.semiemp"></a>
## 半经验方法（Semiempirical Methods）

半经验 INDO/S 方法非常适合计算中等至较大尺寸有机和无机分子的吸收谱。
该方法已由已故的 M. C. Zerner 针对光谱学进行了参数化，
至少以我的经验来看，它对许多体系都工作得很好。
采用半经验方法可以方便地计算大分子的许多激发态。
例如，考虑下面对一个双组氨酸配位的铁卟啉模型（Fe(II) 态）的计算，
该体系包含 92 个原子，单激发空间中约有 $\approx$ 16,500 个 CSF。
然而在普通计算机上只需几分钟即可预测前 40 个激发态。

计算得到的光谱与实验基本相符，显示出约 400 nm 处的一个巨大谱带
（著名的 Soret 带）以及 500 至 550 nm 之间较小但仍然很强的谱带
（Q 带）。在约 $\approx$ 10,000 cm$^{-1}$ 以下没有预测到吸收。

<a id="sec:spectroscopyproperties.tddft.hf"></a>
## Hartree-Fock 波函数（Hartree-Fock Wavefunctions）

将上述步骤应用于纯 Hartree-Fock 时，得到的是"无规相位近似"（RPA）
或单激发组态相互作用（CIS）模型（当有效使用 Tamm-Dancoff 近似 TDA 时）。
一般而言，RPA 和 CIS 计算与实验激发能的符合并不好，
误差达 1–5 eV 是常见的。因此 HF/CIS 主要是一种定性工具，
或者在无法进行更广泛、更均衡的 CI 计算时，可在谨慎的前提下
用于较大的分子。

<a id="sec:spectroscopyproperties.tddft.dft"></a>
## 非杂化与杂化 DFT（Non-Hybrid and Hybrid DFT）

对于 DFT 泛函，可以在完整的 TD-DFT（式 [Eq](#eqrpa)）处理
和所谓的 Tamm-Dancoff 近似（TDA）之间进行选择。

<a id="eqrpa"></a>

$$
\left(\begin{array}{cc}
 A & B \\
 B* & A* \\
\end{array} \right) \left(\begin{array}{c}
 X \\
 Y  \\
\end{array} \right) = \left(\begin{array}{cc}
 \omega & 0 \\
 0 & -\omega \\
\end{array} \right) \left(\begin{array}{c}
 X \\
 Y  \\
\end{array} \right)\qquad \text{(eqrpa)}
$$

TDA 就是把 RPA 简化为 CIS 的那个近似（即忽略所谓的 "B" 矩阵，
见式 [Eq](#eqtda)）。两种方法得到的垂直激发能结果通常非常接近。

<a id="eqtda"></a>

$$
A X_{\text{TDA} } = \omega_{\text{TDA} } X_{\text{TDA} }\qquad \text{(eqtda)}
$$

一般情况下，自旋限制情形下单重态–单重态激发的矩阵 "A" 和 "B"
的矩阵元由式 [Eq](#eqamat) 和 [Eq](#eqbmat) 给出。

<a id="eqamat"></a>

$$
\begin{split}
A_{ia,jb} = & \delta_{ij} \delta_{ab} ( \epsilon_{a} - \epsilon_{i} )  + 2 (ia|jb) - a_{\text{X} } (ij|ab) \\
            & + (1 - a_{\text{X} }) (ia|f_{\text{XC} }|jb)
\end{split}\qquad \text{(eqamat)}
$$

以及

<a id="eqbmat"></a>

$$
B_{ia,jb} =  2 (ia|bj)  - a_{\text{X} } (ib|aj) + (1 - a_{x}) (ia|f_{\text{XC} }|bj) \text{.}\qquad \text{(eqbmat)}
$$

其中 $i,j$ 表示占据轨道，$a,b$ 表示虚轨道。$a_{\text{X} }$
是密度泛函中非局域 Fock 交换的份额。若 $a_{\text{X} }$ 等于一，
则式 [Eq](#eqrpa) 和 [Eq](#eqtda) 对应于基于 Hartree-Fock 基态
行列式的 RPA 和 CIS 情形。

TDA 实际上是 TD-DFT 的默认方法，可通过以下方式关闭：

```orca
%tddft
  TDA  false
end
```

在某些情况下，杂化泛函给出的结果明显优于纯泛函，
因为它们受自相互作用误差的影响较小。在这些情况下，
RIJCOSX 程序[neese2009chemphys](../../bibliography.md) [izsak2011jchemphys](../../bibliography.md)[Helmich-Paris2021a](../../bibliography.md)
能在这类计算中带来非常大的加速，而精度几乎无损失[petrenko2011jchemphys](../../bibliography.md)，
并且当 SCF 也使用它时会默认开启。

<a id="sec:spectroscopyproperties.sftddft.dft"></a>
## 共线自旋翻转 TDA（Collinear Spin-Flip TDA, SF-TD-DFT） 

通过 CIS/TD-DFT 获得激发态的另一条途径是所谓的自旋翻转方法
（一篇很好的综述见参考文献 [casanova_spin-flip_2020](../../bibliography.md)）。其思路是
从一个 UHF 态出发，然后"翻转"一个 alpha 电子以产生
$MS_{SF} = MS_{UHF} - 1$ 的态。为此，我们只寻找从 alpha 轨道到
beta 轨道的激发，这使得 TDA 中的 A 矩阵更加简单：

$$
A_{i\bar a,j\bar b}^{SF} = \delta_{ij} \delta_{\bar a\bar b} ( \epsilon_{\bar a} - \epsilon_{i} ) 
- a_{\text{X} } (ij|\bar a\bar b)\qquad \text{(eqbmat_sf)}
$$

其中上划线表示 beta 轨道，无上划线表示 alpha 轨道。

!!! note
    请注意，对于纯 DFT（$a_X=0$，不含 HF 贡献），
    A 矩阵仅基于轨道能量构建，因此在泛函中含有相当比例的 HF 交换总是更好的！

为便于讨论从 SF-TDA 得到的结果，让我们仔细观察下图所示的
一些可能的激发：

<a id="fig:sf-td-dft"></a>
*自旋翻转算符对 UHF（$MS=3$）波函数的作用。
"自旋完备"的态是 $S^2$ 算符的本征矢，而"自旋不完备"的则不是。
此处 alpha 与 beta 轨道用相同能量表示，仅为简化图像。
改编自前述综述。*

重要的是要注意，并非所有 SF 激发都产生 $S^2$ 算符本征值的行列式。
这意味着，取决于最终 SF 态中这些"自旋不完备"激发所占的比例，
自旋污染可能很高，在这种情况下会预测出 $\langle S^2 \rangle \simeq 1$ 的态。
这些是 SF 理论中未定义的态，应谨慎对待。

!!! warning
    - 任何 SF 方法只能从 UHF 波函数出发使用，且多重度至少为 3！

## 通过 LR-CPCM 理论引入溶剂化效应（Including solvation effects via LR-CPCM theory）

由 Cammi 和 Tomasi 发展的 LR-CPCM 理论[cammi_fast_2000](../../bibliography.md)，
已针对激发态的能量和梯度加以实现。
当基态也请求使用 CPCM 时，它会默认开启。

主要变化在于，式 [Eq](#eqrpa) 的 $\mathbf A$ 部分中现在出现了一个
与溶剂化效应相关的 $G_{ia,jb}$ 项。

$$
\begin{split}
A_{ia,jb} = & \delta_{ij} \delta_{ab} ( \epsilon_{a} - \epsilon_{i} )  + 2 (ia|jb) + 2 G_{ia,jb} \\
& - a_{\text{X} } (ij|ab) + (1 - a_{\text{X} }) (ia|f_{\text{XC} }|jb)
\end{split}\qquad \text{(eqbmat_lrcpcm)}
$$

其中 $G_{ia,bj}$ 定义为：

$$
G_{ia,jb} = ( V_{ia})^T  q_{jb}\qquad \text{(lrcpcm_G)}
$$

### 平衡与非平衡条件（Equilibrium and non-equilibrium conditions）

这些电荷 $q_{jb}$ 按 [cpcm.detailed](#sec:essentialelements.solvationmodels.cpcm.detailed)
中所述的同样方式计算，但对于激发态，
可根据体系动力学使用两个不同的 $\varepsilon$ 值：

-   **非平衡（Non-equilibrium）**：若计算假设电子激发非常快，
    溶剂来不及在溶质周围重新组织，则使用溶剂的 $\varepsilon_{\in f}$，
    它等价于折射率的平方。若想计算垂直激发能，就属于这种情况，
    并且在该情形下它是默认选项。

-   **平衡（Equilibrium）**：若假设激发态完全溶剂化，
    则应使用溶剂的真实介电常数 $\varepsilon$。
    几何优化、频率计算或 ORCA_ESD 内部计算即属于这种情况。
    只要请求了解析梯度，该选项就会默认开启。

无论如何，这些条件都可通过标志 CPCMEQ 控制，
用户可将其设为 TRUE 或 FALSE，从而覆盖默认值。

这些选项对所有 CIS/TD-DFT 情形均可用：单重态、自旋适配三重态、
UHF 以及自旋翻转变体。它也适用于双杂化泛函，
以及请求 SOC 的场合。

## 简化 TDA 与 TD-DFT（Simplified TDA and TD-DFT）

ORCA 也支持使用 S. Grimme 的简化 Tamm-Dancoff 方法（sTDA）计算激发态
[GrimmeSTDA](../../bibliography.md)。sTDA 特别适合计算很大体系的吸收谱。
sTDA 以及简化含时密度泛函理论（sTD-DFT）[BannwarthSTDDFT](../../bibliography.md) 方法
都需要一次（杂化）DFT 基态计算。对于大体系，推荐使用
范围分离杂化泛函（例如 $\omega$B97X）。[RisthausRSHSTDA](../../bibliography.md)\
尤其是 sTD-DFT 方法能给出好得多的电子圆二色（ECD）谱，
应将其用于该目的。

### 理论背景（Theoretical Background）

下面简要概述该理论。更多细节请参阅原始文献
[GrimmeSTDA,BannwarthSTDDFT](../../bibliography.md)。在 sTDA 中，式 [Eq](#eqtda) 的 TDA 本征值问题
采用经过截断和半经验简化的 $A^{\prime}$ 矩阵求解。
截断会忽略所有超出所关心能量范围的激发，
但少数强耦合的激发除外。式 [Eq](#eqamat) 中的矩阵元
通过忽略密度泛函的响应、并把剩余的双电子积分近似为
跃迁/电荷密度单极子之间的阻尼库仑相互作用而加以简化。
下文中，指标 $i,j$ 表示占据轨道，$a,b$ 表示虚轨道，
$p,q$ 表示任意一种轨道。

<a id="eqamatstda"></a>

$$
A^{\prime}_{ia,jb} = \delta_{ij} \delta_{ab} ( \epsilon_{a} - \epsilon_{i} )  + \sum\limits_{A,B}^{N_{\text{atoms} }}
( 2 q^{A}_{ia} \gamma^{K}_{AB} q^{B}_{jb}  - q^{A}_{ij} \gamma^{J}_{AB} q^{B}_{ab} )\qquad \text{(eqamatstda)}
$$

$q^{A}_{pq}$ 与 $q^{B}_{pq}$ 分别是位于原子 $A$ 和 $B$ 上的
跃迁/电荷密度单极子。它们由 Löwdin 布居分析得到
（见 [pop.loewdin](#sec:spectroscopyproperties.pop.loewdin) 一节）。
$\epsilon_{p}$ 是轨道 $p$ 的 Kohn-Sham 轨道能。
$\gamma^{K}_{AB}$ 与 $\gamma^{J}_{AB}$ 分别是用于交换型（$K$）和
库仑型（$J$）积分的 Mataga-Nishimoto-Ohno-Klopman 阻尼库仑算符。

$$
\gamma_{AB}^J=\left(\frac{1}{(R_{AB})^{\beta}+(a_{\text{X} } \eta)^{-\beta} }\right)^{\frac{1}{\beta} }\qquad \text{(eqgammaj)}
$$

$$
\gamma_{AB}^K=\left(\frac{1}{(R_{AB})^{\alpha}+\eta^{-\alpha} }\right)^{\frac{1}{\alpha} }\qquad \text{(eqgammak)}
$$

其中 $\eta$ 是原子 $A$ 与 $B$ 化学硬度的算术平均值。
$\alpha$ 和 $\beta$ 是该方法的参数，由下式给出：

$$
\alpha = \alpha_{1} + a_{x} \alpha_{2}\qquad \text{(eqalphastda)}
$$

$$
\beta = \beta_{1} + a_{x} \beta_{2}\qquad \text{(eqbetastda)}
$$

对于任何全局杂化泛函，$\alpha_{1}$、$\alpha_{2}$、
$\beta_{1}$ 和 $\beta_{2}$ 都是相同的。此时 $\alpha$ 与 $\beta$
只依赖于 Fock 交换的份额（$a_{\text{X} }$）。
对于范围分离杂化泛函则不同，其 $\alpha_{2}$ 与 $\beta_{2}$ 被设为零。
$\alpha_{1}$、$\beta_{1}$ 以及 sTDA 处理所用的 $a_{x}$ 值
都为每种范围分离杂化泛函单独拟合。[RisthausRSHSTDA](../../bibliography.md)
由式 [Eq](#eqamatstda) 可以看出，该方法在渐近意义上是正确的，
这对于电荷转移型激发至关重要。

在 sTD-DFT 中，式 [Eq](#eqrpa) 采用简化的矩阵 $A^{\prime}$（见上）
和 $B^{\prime}$ 求解。

$$
B^{\prime}_{ia,jb} = \sum\limits_{A,B}^{N_{\text{atoms} }} ( 2 q^{A}_{ia} \gamma^{K}_{AB} q^{B}_{bj}  - a_{\text{X} } q^{A}_{ib} \gamma^{K}_{AB} q^{B}_{aj} )\qquad \text{(eqbmatsrpa)}
$$

该方法给出更好的跃迁偶极矩，因而谱图也更好，
但比 sTDA 更加昂贵（对典型体系约为 2–5 倍）。
sTDA 与 sTD-DFT 中使用的参数完全相同。
该方法**没有**额外拟合的参数。

## 双杂化泛函与双激发校正（Double-hybrid functionals and Doubles Correction）

程序可以对 CIS 激发能计算双激发校正。该理论出自 Head-Gordon
及其合作者。[headgordon1994](../../bibliography.md) 基本思路是计算一个对 CIS 激发态的微扰估计
（受 EOM-CCSD 理论启发），使之与 MP2 基态能量相容。
在许多情况下，这相对 CIS 本身是显著的改进，并且代价合理，
因为该校正是*事后*（a posteriori）计算的。当然，若 CIS 对激发态的
预测很差，(D) 校正——由于其微扰本质——无法弥补定性错误的
激发态波函数。

此外——或许更重要的是——(D) 校正与双杂化泛函的哲学相容，
若要用这些泛函计算激发态就应当使用它。结果通常远好于 TD-DFT，
因为大量 HF 交换使得自相互作用误差远小于其他泛函，
并且在 (D) 校正之后，结果不再受 TD-DFT 计算中随 HF 交换份额增加
而通常出现的跃迁能高估之苦。

由于该计算需要相当大的积分变换，若不引入近似就会将其限制在
相当小的分子上，我们决定只实现它的 RI 版本。
在该近似下，基函数超过 1000 个的体系也完全在实现的能力范围之内。

由于总是有三步计算：MP2–CIS 求解–(D) 校正，
我们实现了若干算法，在特定情形下每一种都可能成为首选方法。
选择取决于体系大小、根的数目、可用主存和可用磁盘空间，
以及系统的 I/O 速率。(D) 校正的形式代价为 $O(N^{5})$，
其前因子高于 RI-MP2。在最好的情况下，
限速步骤是 "U 项" 中对电子对贡献的计算，
它对闭壳层体系而言*每个态*需要 RI-MP2 计算两倍的代价。

(D) 校正的使用很简单。只需写：

```orca
! HF DEF2-SVP DEF2-SVP/C TightSCF
%cis dcorr n # n=1-4. The meaning of the four algorithms is
             # explained below.
   # algorithm 1 Is perhaps the best for small systems. May use a
   #             lot of disk space
   # algorithm 2 Stores less integrals
   # algorithm 3 Is good if the system is large and only a few
   #             states are calculated. Saves disk and main
   #             memory.
   # algorithm 4 Uses only transformed RI integrals. May be the
   #             fastest for large systems and a larger number
   #             of states
end
```

!!! note
    -   CIS(D) 相对 CIS 往往是相当大的改进。

    -   在涉及的全部三个代码部分（MP2、CIS、(D)）中都遵守存储格式 FLOAT。
        与默认的双精度版本相比，它将磁盘和主存的使用减少一半。
        精度损失应当可以忽略；不过——在科学中一向如此——最好再核对一下。

    -   (ab|Q) 积分列表对许多体系而言可能是最大的，
        很容易占据数 GB 的磁盘空间（因此有算法 2 和 3）。
        然而，除非您遇到 I/O 瓶颈，这些磁盘空间往往是值得的。

    -   (ia|jb) 和 (ij|ab) 积分列表也相当大，但处理效率相对较高。
        尽管如此，I/O 仍可能成为问题。

    -   (D) 校正的代价为 O(N$^{5})$，因此与 RI-MP2 相当。
        由于与 RI-MP2 相比 (D) 还有相当多的工作要做，预计计算会更耗时。
        在最基本的实现中，每个根的代价大约是 RI-MP2 时间的两倍。

    -   (D) 校正与双杂化密度泛函的哲学相容，
        当这些泛函与 TD-DFT 组合时应当使用它。
        程序将此作为默认，但不会强制执行。(D) 校正在 TD-DFT 和 TDA-DFT
        语境下均可使用。

    -   在我们的实现中，它只与 RI 近似一起实现，
        因此您需要提供合适的（"/C"）拟合基组。

    -   程序会自动使 RI-MP2 模块与 (D) 校正一起运行。
        这将使必要的积分对 CIS 模块变为可用。

    -   以 RI-AO 直接方式构造 CIS 残差向量的交换贡献，
        在激发态数目较多时会变得相当昂贵。
        若对较大的体系只需计算一两个激发态，这可能是个好选择。

    -   单重–三重激发可分别通过在 %cis 或 %tddft 块中设置 TRIPLETS TRUE
        来计算。该实现在参考文献 [tripletTDDH](../../bibliography.md) 中已针对双杂化泛函进行过测试。

    -   对于自旋适配三重态（TRIPLETS TRUE），目前唯一可用的选项是 DCORR 1。

    -   Schwabe 和 Goerigk 定义的、TD- 和 TDA-DFT 框架内双杂化泛函的
        自旋组分缩放与自旋相反缩放技术[schwabetdpbe02017](../../bibliography.md)，
        可在 %tddft 块中以与上文 SCS-CIS(D) 相同的方式调用。
        虽然用户自定义参数可以这样输入，
        但通过常规关键词还可使用一系列新泛函，
        它们采用本文所述的 SCS/SOS-CIS(D) 实现。[SCSTDDHDFs](../../bibliography.md)
        这些泛函的列表见 [dft.basicusage](#sec:modelchemistries.dft.basicusage) 一节。

    -   含时双杂化泛函的使用应按如下方式引用：
        对任意双杂化泛函的 TD 或 TDA[tdtdadftgrimme2007](../../bibliography.md)、
        TD-B2GPLYP[goerigktdb2gplyp2009](../../bibliography.md)、TDA-PBE0-DH 或 TDA-PBE0-2[meotdapbe02013](../../bibliography.md)、
        TD-PBE0-DH、TD-PBE0-2 或 TDA-B2GP-PLYP[schwabetdpbe02017](../../bibliography.md)、
        TD-$\omega$B2PLYP 或 TD-$\omega$B2GPPLYP[goerigk2019RSDHTDDFT](../../bibliography.md)、
        TDA-$\omega$B2PLYP 或 TDA-$\omega$B2GPPLYP[tripletTDDH](../../bibliography.md)、
        TD(A)-RSX-QIDH 或 TD(A)-RSX-0DH[tripletTDDH](../../bibliography.md)、
        TDA-PBE-QIDH[RSXQIDH](../../bibliography.md)、TD-PBE-QIDH[ADAMOIJQC2020](../../bibliography.md)、
        TD(A)-DSD-BLYP 或 TD(A)-DSD-PBEP86，
        或 2017 年的许多其他自旋组分缩放双杂化泛函的 TD(A)-DFT[schwabetdpbe02017](../../bibliography.md)、
        TD(A) $\omega$B88PP86 或 TD(A) $\omega$PBEPP86，
        或 2021 年的许多其他自旋组分与相反缩放双杂化泛函的 TD(A)-DFT[SCSTDDHDFs](../../bibliography.md)。

    -   请注意，只有当对 Casanova-Páez 和 Goerigk 在 2021 年提出的泛函
        请求 TD(A)-DFT 计算时，才会自动使用 SCS/SOS-CIS(D)。[SCSTDDHDFs](../../bibliography.md)
        在这些情形下不必设置 "doscs"。
        对于 PWPB95、$\omega$wB97X-2 或 DSD 泛函，不会自动使用 SCS/SOS-CIS(D)。

<a id="sec:spectroscopyproperties.tddft.spinorbitcoupling"></a>
## 自旋–轨道耦合（Spin-orbit coupling）

也可以通过准简并微扰理论（quasi-degenerate perturbation theory）
在由 TD-DFT 计算得到的单重态与三重态之间引入自旋–轨道耦合
（相关文献见 [de_souza_phosp_2019](../../bibliography.md)），
做法与 ROCIS 中类似。为此，必须将标志 DOSOC 设为 TRUE。
约化矩阵元会被打印，所有 SOC 耦合态之间的新跃迁偶极矩
也会在常规跃迁偶极矩之后打印。该选项目前仍与双杂化泛函不兼容，
但适用于包括 CPCM 在内的所有其他情形。
所有与 SOC 积分相关的选项都可以像往常一样在 %rel 块中更改。

```orca
%CIS DOSOC  TRUE END
```

请记住，就目前而言，您只能计算激发单重态与自旋适配三重态之间的 SOC。
从 UHF/UKS 波函数出发没有 SOC。若想打印更多信息，
例如完整的 SOC 矩阵或三重–三重耦合，请设置更高的 PRINTLEVEL。

<a id="sec:spectroscopyproperties.tddft.spinorbitcoupling.ECPs"></a>
### SOC 与 ECPs（SOC and ECPs） 

ORCA 目前没有 ECP 的 SOC 积分，在 SOC 模块中默认忽略它们。
若您尝试将 ORCA 与 ECPs 一起使用，会打印一条中止消息。
如果绝对必须使用 ECPs，例如对嵌入势，请使用：

```orca
%TDDFT FORCEECP TRUE END
```

注意：不要在 SOC 可能很重要的原子上使用 ECPs。
在这种情况下，务必使用全电子基函数，否则结果将没有意义。

<a id="sec:spectroscopyproperties.tddft.compute"></a>
## 计算细节（Computational Aspects）

<a id="sec:spectroscopyproperties.tddft.compute.aobasis"></a>
### RI 近似（AO 基组）（RI Approximation (AO-Basis)） 

若 SCF 计算使用了 RI 近似，TD-DFT 计算中也会使用它。
RI 近似可节省大量时间，同时给出几乎相同的结果
（误差通常 $<$0.1 eV），一般推荐使用。若泛函是杂化泛函，
RI 近似只应用于库仑项，而交换项将按以前的方式处理。
在 SCF 中您可以用关键词（`! RIJONX`）启用这一特性，
它随后也会在 TD-DFT 计算中使用。
同样，RIJCOSX 近似可用于 TD-DFT 和 CIS 计算，
能带来非常大的加速，而精度几乎无损失。

<a id="sec:spectroscopyproperties.tddft.compute.integral"></a>
### 积分处理（Integral Handling）

若 SCF 计算以积分直接方式（integral direct）进行，
CIS/TD-DFT 计算也会这样做。因此计算中不会出现由
大积分变换或大磁盘空间需求引起的瓶颈。
例外是上一节所述的基于 MO 的 RI 近似。

<a id="sec:spectroscopyproperties.tddft.compute.valence"></a>
### 价态与 Rydberg 态（Valence versus Rydberg States）

对于价激发态，常用的轨道基组是合理的。
因此，使用极化双 zeta 基组即可得到合理的结果。
DFT 计算尤其有一个优点，即不过分依赖基组。

若需要 Rydberg 态，应确保基组中存在弥散函数。
您总是可以使用专为弥散设计的基组，例如 DEF2-TZVPD、ma-DEF2-TZVP
或 aug-cc-pVTZ，或者向常规基组添加一些额外的弥散基函数。
这些可以添加到任何"普通"基组上。例如，下例为激发态计算提供了
一个相当高质量的、基于 Ahlrichs 基组的基组：

```orca
%basis 
  # augment the carbon basis set by diffuse functions
  addgto 6
    s 1
       1 0.01 1.0
    p 1
       1 0.01 1.0
    d 1
       1 0.07 1.0
    end
end
```

!!! note
    若想扩充某个基组，合理的做法是先运行一次预备 SCF 计算，
    并使用 `%output print[p_basis] 2 end`。
    这将为您提供基函数及其指数的详细列表。
    然后可以用 `AddGTO` 命令像上例那样添加额外的 s、p 以及可能的 d 函数。
    合理的做法是将弥散函数的指数相对原基组中最小的指数大约减小 3 倍。

<a id="sec:spectroscopyproperties.tddft.compute.restrictionsRS"></a>
### 范围分离密度泛函的限制（Restrictions for Range-Separated Density Functionals）

范围分离（包括杂化和双杂化）密度泛函有若干限制。
目前它们只实现为可与 RIJONX、RIJCOSX 和 NORI 积分方案中的
基于 AO 的算法一起工作。此外，渐近校正已被禁用。
不过，激发态的核梯度现在已可用，包括三重态。
请注意，必须在 %CIS 或 %TDDFT 下将 IROOTMULT 标志设为 TRIPLET 才能得到它。

<a id="sec:spectroscopyproperties.tddft.compute.printGrad"></a>
### 顺序打印额外梯度（Printing Extra Gradients Sequentially）

若想为外部应用程序或任何其他原因打印额外的梯度，
可以对单重态和三重态分别使用关键词 SGRADLIST 和 TGRADLIST。
这将在 CIS/TDDFT 运行之后按顺序打印这些梯度。
若在单重态列表中放入 0，基态梯度也会被加入，且总在最后。

```orca
%TDDFT SGRADLIST  0, 1, 2
       TGRADLIST  2, 3 
END
```

要将这些梯度保存到文本文件中，请使用：

```orca
%METHOD STORECISGRAD TRUE END
```

<a id="sec:spectroscopyproperties.tddft.restart"></a>
## 重启 TD-DFT 计算（Restarting TD-DFT Calculations） 

TD-DFT 振幅默认存储在 GBW 文件中。这也意味着，若提供合适的 GBW 文件，
TD-DFT 计算可以重启。重启相当灵活：它允许源计算与目标计算之间
几何结构、基组或密度泛函发生变化。但是，源计算的根数必须至少与目标计算
相同或更多，源计算根数更少是不允许的。
下面是一个简单例子：

```orca
* gzmt 0 1 
  O
  H  1 1.0 
  H  1 1.0 2 104.0
*

%compound
 New_Step 
   ! B3LYP def2-SVP def2/J VeryTightSCF PModel 
   %Base "FirstJob"
   %cis nroots   10
        triplets true
        tda      true
        end 
  Step_end
 
  New_Step
   ! B3LYP def2-SVP def2/J VeryTightSCF 
   %Base "SecondJob"
   %cis nroots   10
        triplets true
        tda      true
        Restart "FirstJob.gbw" 
        end 
  Step_end
 
endrun; 
```
 
!!! note
    - This is supposed to work for all combinations of TDA or RPA, singlets and triplets and also for spin-flip TD-DFT calculations. 
    - We make several consistency checks but it will certainly be possible to create nonsensical inputs that will fail – please proceed with caution. 

<a id="sec:spectroscopyproperties.tddft.xas"></a>
## 用 TD-DFT 计算 X 射线吸收谱（Use of TD-DFT for the Calculation of X-ray Absorption Spectra）

原则上，X 射线吸收谱就是"普通"的吸收谱，
只不过是在特殊的高能波长范围测量。由于所用辐射能量很高
（数千 eV），被激发的是内层电子而非价电子。这带来两个后果：
a) 该方法具有元素特异性，因为内层能级能量相当清晰地划分为
特定元素的特征区域；b) 辐射波长如此之短，
以至于光–物质相互作用展开中的高阶项变得重要。
最明显的是，四极强度变得重要。

X 射线吸收谱一般可分为三个区域：a) 前边（pre-edge），
对应于内层电子跃迁到低能虚轨道并形成束缚态；
b) 上升边（rising edge），对应于激发到勉强束缚的高能态；
c) 扩展 X 射线吸收精细结构区域（EXAFS），
对应于电子从吸收原子逸出并在邻近原子上散射。

用这里描述的简单 TD-DFT 计算，注意力集中在前边区域。
上升边和 EXAFS 区域都不能用标准电子结构方法合理描述，
不应尝试比较。此外，这些计算仅限于 K 边，
因为 L 边的计算要繁重得多，需要对核心空穴的自旋–轨道耦合进行细致处理。

显然，试图计算足够多的态来覆盖从前边区域到价层的所有跃迁是不现实的。
因此，人们改为手工挑选合适的给体核心轨道，
只允许从这些轨道激发到整个虚空间。
已有研究表明这一近似是合理的。[debeer2008jpca](../../bibliography.md)
应区分两种情形：第一，所涉及的核心轨道可能很好地孤立且定义明确。
若分子中只有一种给定类型的金属，金属 1s 轨道通常属于这种情况。
第二，分子中可能存在多个同类原子，它们的核心轨道按群论要求
形成相应的对称化线性组合。在后一种情形下需要特殊处理：
突变近似（sudden approximation）要求激发从局域核心轨道发生。
在程序的早期版本中，您必须手动定域核心空穴。
在当前版本中有一个自动过程，如下所述。

一个典型例子是 TiCl$_4$。若想计算钛的 K 边，合适的输入如下：

### 困难情形的根跟踪方案（Root Following Scheme for Difficult Cases）

若几何优化中某一步之后发生根翻转（root flipping），
可能无法用常规方法收敛激发态几何结构。
为帮助这类情形，可将标志 FOLLOWIROOT 设为 TRUE。
然后，激发态波函数将被分析并与参考态比较（详见下文），
IROOT 将被自动调整以持续跟踪目标态。

这类计算的一个例子是：

```mol
title: structure 15
theme: chem311
height: 320px
representation: ball-stick
--- xyz ---
4
structure (0 1)
N           0.0          0.0          0.0
H           0.0          0.0          1.0
H           0.0         -0.9          0.5
H           0.0          0.9          0.5
--- input ---
! wB97X OPT 

%tddft
 NRoots        5   
 IRoot         3   
 FOLLOWIROOT   TRUE
end

* xyz 0 1 
 N 0.0  0.0  0.0 
 H 0.0  0.0  1.0 
 H 0.0 -0.9  0.5 
 H 0.0  0.9  0.5 
*
```

这将要求优化氨的第三激发态。
在某个时刻会发生态交叉，原先的态 3 现在变成态 2。
算法会识别这一点并自动更改 `IROOT` 标志，以继续跟踪同一个态：

```orca
The IROOT now is:                                ... 2
```

`FOLLOWIROOT` 对自旋适配三重态和自旋翻转态同样有效。

若您希望只与**最初**计算的激发态密度进行比较，
例如几何优化第一轮得到的那个，可以使用 FIRKEEPFIRSTREF，例如：

```orca
%tddft
  NRoots           5
  IRoot            3
  FOLLOWIROOT      TRUE
  FIRKEEPFIRSTREF  TRUE # default false
end
```

### 跟踪 IROOT 的判据 —— 自 ORCA6 起（Criteria to Follow IROOTs - starting from ORCA6）

从 ORCA6 开始，我们有了一个稳健得多的算法来跟踪这些激发态，
其灵感来自近期的一些文献
[steinmetzer_pysisyphus_2021](../../bibliography.md) [campetella_following_2020](../../bibliography.md)。
每次用 CIS/TDDFT 计算激发态之后，该算法现在工作如下：

1. 给定一个参考态，取与其能量差不超过 1 eV 的所有态。
我们不想检查能量相差太远的态。
由 `%TDDFT FIRENTHRESH 1.0 END` 控制，单位为 eV。
2. 然后取 $\hat{S}^2$ 差异不大于 0.5 的所有态。
我们不想把单重态与三重态相比较。由 `%TDDFT FIRS2THRESH 0.5 END` 控制。
3. 计算所有态与参考态之间跃迁密度的重叠 —— 这是核心部分。
4. 若出现歧义 —— 即两个态的重叠仅相差 0.05 ——
则取跃迁偶极角更接近的那一个。由 `%TDDFT FIRSTHRESH 0.05 END` 控制。
5. 将 IROOT 更新为在所有这些测试中表现最好的那个态。

!!! note
    这些 `FIR` 关键词是 **F**ollow **IR**oot 特有的。

现在默认情况下，若态的分离非常清晰，我们也可能不时更新参考态。
其工作方式是：

1. 若最佳重叠大于 `FIRMINOVERLAP`（默认为 0.5）且 `FIRDYNOVERLAP` 为 `FALSE`，
我们就认为重叠足够好，并总是更新参考态。
然而默认是 `FIRDYNOVERLAP TRUE`，这意味着还有第二重稳健性检查。
2. 若 `FIRDYNOVERLAP TRUE` 且最佳重叠大于 0.5（或 `FIRMINOVERLAP`），
我们将检查最佳与次佳态之间的 `ratio`（比值）。
若该 `ratio` 介于 0.3 与 0.6 之间
（由 `%TDDFT FIRDYNOVERRATIO 0.3,0.6 END` 控制），
说明最佳与次佳之间分离清晰，可以安全地更新参考态。
若该比值太接近 1，两个态过于相似，更新参考态会有危险。
若太接近零，它们容易区分，我们还不需要更新参考态
[steinmetzer_pysisyphus_2021](../../bibliography.md)。

!!! warning
    必须强调，这不一定能解决所有问题
    （若体系高度对称，根翻转可能格外严重），
    因为激发态在优化过程中可能变化太大。
    若发生这种情况，建议在若干步之后重启计算，
    并检查您仍想要哪个 IROOT。在计算数值梯度和 Hessian 时
    若怀疑位移之后发生根翻转，也可使用该方法。

!!! warning
    该算法完全通用，只要存在跃迁密度，应当适用于任何激发态方法。
    将来条件允许时我们会纳入更多方法。

### SOC 态的几何优化（Geometry Optimization of SOC States） 

若想计算 SOC 态的几何结构，只需选择 `SOCGRAD TRUE` 和一个给定的 `IROOT`。
在选出贡献大于 0.01% 的 CIS/TD-DFT 态之后，
将计算加权的"非弛豫"梯度。每个梯度分别计算，
之后最终 SOC 梯度作为加权和得到。
在这种情况下设置 `IROOT 0` 对应于请求 SOC 基态，
它**不一定**等于 HF/DFT 的基态。

参数 `HessName` 指定包含频率计算中得到的核 Hessian 矩阵的文件名。
Hessian 矩阵用于构造简正模轨迹。关键词 `MList` 给出需要扫描的简正模列表。
参数 `RSteps` 和 `LSteps` 指定沿列表中每个模的正方向和负方向的步数。
一般而言，对给定的一组参数

```orca
mlist m1,m2,...mn
rsteps rm1,rm2,...rmn
lsteps lm1,lm2,...lmn
```

需要进行单点计算的位移几何结构总数等于
$\prod\limits_{m_{i} } { \left({r_{m_{i} } +l_{m_{i} } +1} \right)}$。
因此，在本例中该数目等于
$\left({ 4+4+1} \right)\left({ 5+5+1} \right)=99$。

`ddnc` 参数以无量纲简正坐标（dimensionless normal coordinates, DNC）
给出列表中各简正模的增量 $\delta q_{\alpha }$。
轨迹的构造方式是使相应的简正坐标在
$-l_{\alpha } \delta q_{\alpha }$ 到 $r_{\alpha } \delta q_{\alpha }$ 范围内变化。
以 DNC 衡量简正模位移是合适的选择，
因为在光谱应用中势能函数 $U$ 通常以 DNC 表示。
特别地，在简谐近似下 $U(q_{\alpha } )$ 在平衡几何附近有非常简单的形式：

$$
U=U_{0} +\sum\limits_\alpha^{3N-6} { \frac{\hslash \omega_{\alpha }
}{2}q_{\alpha }^{2} }\qquad \text{(eqn:213)}
$$

其中 $\omega_{\alpha }$ 是第 $\alpha$ 个模的振动频率。

无量纲简正坐标 $q_{\alpha }$ 可与原子笛卡尔位移矢量
$\delta \mathrm{X }$ 如下关联：

$$
q_{\alpha } =\left({ \frac{\omega_{\alpha } }{\hslash } }
\right)^{\frac{1}{2} }\sum\limits_{k=1}^{3N}
{L_{k\alpha } \delta X_{k} \sqrt{ M_{k} } }\qquad \text{(eqn:214)}
$$

其中 $\left\{{ L_{k\alpha } } \right\}$ 是对质量加权 Hessian 矩阵
进行数值对角化得到的正交矩阵，$\mathrm{M }$ 是原子质量矢量。
相应地，与给定无量纲简正坐标 $q_{\alpha }$ 对应的原子笛卡尔位移由下式给出：

$$
\delta X_{k} =\left({ \frac{\hslash }{\omega_{\alpha } } }
\right)^{\frac{1}{2} }L_{k\alpha } q_{\alpha } \left({ M_{k} }
\right)^{-\frac{1}{2} }\qquad \text{(eqn:215)}
$$

另外，也可以在输入中为每个简正模指定笛卡尔增量。
在这种情况下，应使用 `dxyz` 关键词代替 `ddnc` 参数，
后面跟笛卡尔位移的值，例如：

```orca
%mtr
   HessName "ethene.hess"
   modetype normal
   MList 9,13
   RSteps   4,5
   LSteps   4,5
   dxyz     0.01, 0.02 # increments in the Cartesian basis
                       # are given in angstrom units
end
```

对沿第 $\alpha$ 个简正模的给定笛卡尔增量 $d_{X,\alpha }$，
原子位移按下式计算：

$$
\delta X_{k} =\frac{d_{X,\alpha } }{\left\| { \mathrm{T }_{\alpha } }
\right\|}L_{k\alpha } \left({ M_{k} } \right)^{-\frac{1}{2} }\qquad \text{(eqn:216)}
$$

笛卡尔基下的矢量 $\mathrm{T }_{\alpha }$ 具有分量
$T_{i\alpha } =L_{k\alpha } \left({ M_{k} } \right)^{-\frac{1}{2} }$，其长度（范数）为
$\left\| { \mathrm{T }_{k} } \right\|$。

增量长度也可以根据式 [Eq](../modelchemistries/mdci.md#eqn:121) 对位移引起的总能量变化
$\Delta E$ 的估计来选取。
$\Delta E$ 的值可通过 `EnStep` 参数指定：

```orca
%mtr
   HessName "ethene.hess"
   modetype normal
   MList 9,13
   RSteps   4,5
   LSteps   4,5
   EnStep   0.001, 0.001 # the values are given in Eh
end
```

所有量子化学方法都必须容忍一定程度的数值噪声，
这些噪声来自有限的收敛阈值或理论流程中引入的其他截断。
因此，合理的选择是让 $\Delta E$ 高于给定计算方法的特征数值噪声水平。

程序运行开始时会创建下列轨迹文件，可在 gOpenMol 中可视化：

-   `BaseName.m9.xyz` 和 `BaseName.m13.xyz` 分别包含沿简正模 9 和 13 的轨迹。

-   `BaseName.m13s1.m9.xyz - BaseName.m13s5.m9.xyz` 包含沿简正模 9 的轨迹，
    对应沿模 13 的不同固定位移，因此文件 `BaseName.m13sn.m9.xyz `对应于
    沿模 13 正方向的第 $n$ 步。

-   `BaseName.m13s-1.m9.xyz - BaseName.m13s-5.m9.xyz` 包含沿简正模 9 的轨迹，
    对应沿模 13 的不同固定位移，因此文件 `BaseName.m13s-n.m9.xyz `对应于
    沿模 13 负方向的第 $n$ 步。

-   `BaseName.m9s1.m13.xyz - BaseName.m9s4.m13.xyz` 包含沿简正模 13 的轨迹，
    对应沿模 9 的不同固定位移，因此文件 `BaseName.m9sn.m13.xyz` 对应于
    沿模 9 正方向的第 $n$ 步。

-   `BaseName.m9s-1.m13.xyz - BaseName.m9s-4.m13.xyz` 包含沿简正模 13 的轨迹，
    对应沿模 9 的不同固定位移，因此文件 `BaseName.m9s-n.m13.xyz` 对应于
    沿模 9 负方向的第 $n$ 步。

沿轨迹的能量单点计算结果将收集在文件
`BaseName.mtr.escf.S.dat`（SCF 总能量）和
`BaseName.mtr.ecis.S.dat`（CIS/TDDFT 总能量）中，
其中 `*.S.dat` 文件名后缀中的 "S" 以与轨迹文件 `*.xyz`
相同的方式指明相应轨迹（例如 `S=”m9s-1.m13”`）。
同样，沿轨迹计算的总能量在 MP2 计算中收集在
`BaseName.mtr.emp2.S.dat` 文件中，MDCI 计算为 `BaseName.mtr.emdci.S.dat `，
CASSCF 为 `BaseName.mtr.ecasscf.S.dat`，
MRCI 为 `BaseName.mtr.emrci.S.dat`。

!!! note
    原则上，简正坐标轨迹可以对任意数目的简正模进行。
    这意味着轨迹中一般会包含沿若干（>2）个模同时位移的几何结构。
    不过，只有对沿不超过 2 个简正坐标同时位移的结构，
    才会生成轨迹文件 `*.xyz` 和相应的 `*.dat` 文件。

<a id="fig:710"></a>
*使用 `orca_cis` 模块对乙烯分子激发态沿 C–C 伸缩简正坐标
（本例中为模 13）进行势能面扫描的结果。*

<a id="sec:spectroscopyproperties.tddft.scan.normalModeScan"></a>
### 不同结构之间的简正模扫描计算（Normal Mode Scan Calculations Between Different Structures）

这类任务允许将两个不同结构之间的 PES 绘制成简正坐标的函数。
H$_{2}$O 分子是一个简单情形，它形式上有 2 个等价的平衡结构，
差别在于 H$_{1}$---O---H$_{2}$ 角（按 BP86/SV(P) 计算分别为
103.5$^{\circ}$ 和 256.5$^{\circ}$）。在这种情况下，
简正模轨迹运行的输入需要用无量纲简正坐标表示两个结构之间的几何差异。
这可在 `orca_vib` 运行中如下完成：

```orca
> orca_vib water.hess ddnc geom.xyz
```

命令行中的第二个参数 ddnc 调用以 DNC 表示的几何差异计算。
两个结构在文件 `geom.xyz` 中指定，该文件有严格的格式：

```orca
2  3
0
        0.000000      0.000000      0.000000
        0.000000      0.607566      0.770693
        0.000000      0.607566     -0.770693
1
        0.000000      0.000000      0.000000
        0.000000     -0.607566      0.770693
        0.000000     -0.607566     -0.770693
```

输入的第一行指定结构数目和原子总数（分别为 2 和 3）。
每个结构的描述以包含该结构编号的新行开始。
第二行中的数字 0 用于表示参考结构。请注意，
原子坐标应以 Å 为单位给出，且顺序与计算 `water.hess` 文件的
频率运行 ORCA 输入中的顺序相同。

`orca_vib` 运行结束时会生成文件 `geom.ddnc`。
它包含 `geom.xyz` 中编号非零的结构与参考结构之间
以无量纲简正坐标表示的几何差异：

```orca
1
1 9
    0       0.000000
    1       0.000000
    2       0.000000
    3       0.000000
    4       0.000000
    5       0.000000
    6       9.091932
    7      -9.723073
    8       0.000000
```

输出文件表明结构差异发生在 2 个简正坐标上：
6（弯曲模）和 7（全对称 O---H 伸缩模）。
根据计算得到的位移模式，可以设计如下在两个结构之间进行
简正模轨迹运行的输入：

```orca
------------------------------------------------------------------------------
                 UNRELAXED CIS/TDA DENSITY POPULATION ANALYSIS
                                   IROOT 1
------------------------------------------------------------------------------
------------------------------------------------------------------------------
                           ORCA POPULATION ANALYSIS
------------------------------------------------------------------------------
Input electron density              ... example5.cispur.singlet.iroot0
BaseName (.gbw .S,...)              ... example5

                    ********************************
                    * MULLIKEN POPULATION ANALYSIS *
                    ********************************

-----------------------
MULLIKEN ATOMIC CHARGES
-----------------------
   0 O :    0.177629
   1 C :   -0.438661
   2 H :    0.130515
   3 H :    0.130518
Sum of atomic charges:   -0.0000000

(...)

                      *****************************
                      * MAYER POPULATION ANALYSIS *
                      *****************************

  NA   - Mulliken gross atomic population
  ZA   - Total nuclear charge
  QA   - Mulliken gross atomic charge
  VA   - Mayer's total valence
  BVA  - Mayer's bonded valence
  FA   - Mayer's free valence

  ATOM       NA         ZA         QA         VA         BVA        FA
  0 O      7.8224     8.0000     0.1776     2.5554     1.4462     1.1092
  1 C      6.4387     6.0000    -0.4387     3.8364     3.1848     0.6516
  2 H      0.8695     1.0000     0.1305     0.9720     0.8521     0.1199
  3 H      0.8695     1.0000     0.1305     0.9720     0.8521     0.1199

  Mayer bond orders larger than 0.100000
B(  0-O ,  1-C ) :   1.4477 B(  1-C ,  2-H ) :   0.8685 B(  1-C ,  3-H ) :   0.8685
```

这里参数 `RSteps`、`LSteps` 和 `ddnc` 的选择使得沿模 6 和 7 扫描时，
相应的无量纲简正坐标分别在 0 $-$ 9.091932 和 -9.723073 $-$ 0 范围内变化，
与文件 `geom.ddnc` 中所示的投影模式一致。
请注意，简正模只定义到一个任意的符号选择。
因此，无量纲位移的绝对符号是不确定的，
原则上在不同的 `orca_vib `运行中可能不同。
重要的是，上例所示的不同结构之间的简正模扫描
必须使用与计算简正模位移时相同的简正模符号。
若 `orca_vib `运行和轨迹计算中使用相同的简正模，该条件即得到满足。
因此，由于 `orca_vib` 计算中简正模存储在 `.hess` 文件中，
轨迹计算中必须使用同一个 Hessian 文件。

<a id="sec:spectroscopyproperties.tddft.nacmes"></a>
## 非绝热耦合矩阵元（Non-adiabatic coupling matrix elements）

CIS 模块可以计算基态与由 IROOT 给出的激发态之间的
非绝热耦合矩阵元（non-adiabatic coupling matrix elements, NACME）：
$\langle \Psi_{GS} | \frac{\partial}{\partial R_x} | \Psi_{IROOT} \rangle$
[send_first-order_2010](../../bibliography.md)。
若主输入中选择了 !CPCM(solvent)，它们也可以包含 LR-CPCM 效应和 ZORA 效应，
并且若 SCF 中选择了 RIJ 和 COSX，也会加以利用。用法很简单，例如：

```mol
title: structure 19
theme: chem311
height: 320px
representation: ball-stick
--- xyz ---
4
structure (0 1)
O   0.000000000  0.000000000  0.611403292
C   0.000000000  0.000000000 -0.613232096
H   0.931880792  0.000000000 -1.200880848
H  -0.931880792  0.000000000 -1.200880848
--- input ---
!PBE0 DEF2-SVP TIGHTSCF
%TDDFT  NROOTS  5
        IROOT   2
        NACME   TRUE
END
* xyz 0 1
O        0.000000000      0.000000000      0.611403292
C        0.000000000      0.000000000     -0.613232096
H        0.931880792      0.000000000     -1.200880848
H       -0.931880792      0.000000000     -1.200880848
*
```

在 %TDDFT 下选择 NACME TRUE，将进行常规梯度计算，
NACME 与之一同计算。在常规梯度输出之后，NACME 将打印为：

```orca
---------------------------------
CARTESIAN NON-ADIABATIC COUPLINGS
       <GS|d/dx|ES>
---------------------------------

1   O   :   -0.161958900   -0.000000135    0.000001029
2   C   :   -0.088213027   -0.000000024    0.000000167
3   H   :    0.226241398    0.000000001   -0.109102154
4   H   :    0.226241406   -0.000000000    0.109102161

Difference to translation invariance:
:    0.2023108777   -0.0000001585    0.0000012017

Norm of the NACs                   ...    0.4002363416
RMS NACs                           ...    0.1155382798
MAX NAC                            ...    0.2262414063
```

NACME 以笛卡尔基给出；这可能与其他一些在简正模基下给出 NACME 的程序不同。
要获得简正模基下的 NACME，可以进行内转换（IC）速率计算
（见 [esd.ic](#sec:spectroscopyproperties.esd.ic)）并从输出文件中获取。

<a id="sec:spectroscopyproperties.tddft.nacmes.etf"></a>
### 含内置电子平移因子的 NACME（NACMEs with built-in electron-translation factor）

如您所见，上述计算并不具有完整的平移不变性！
这是从 CI 波函数计算的 NACs 的一个特性，源于 Born-Oppenheimer 近似。
可以通过引入所谓的"电子平移因子"（electron-translation factors, ETFs）
[fatehi_analytic_2011](../../bibliography.md) 得到某种程度的修正，
在 %TDDFT 下用 ETF TRUE 添加。现在使用输入：

```mol
title: structure 20
theme: chem311
height: 320px
representation: ball-stick
--- xyz ---
4
structure (0 1)
O   0.000000000  0.000000000  0.611403292
C   0.000000000  0.000000000 -0.613232096
H   0.931880792  0.000000000 -1.200880848
H  -0.931880792  0.000000000 -1.200880848
--- input ---
!PBE0 DEF2-SVP
%TDDFT  NROOTS  5
     IROOT   2
     NACME   TRUE
     ETF     TRUE
END
* xyz 0 1
O        0.000000000      0.000000000      0.611403292
C        0.000000000      0.000000000     -0.613232096
H        0.931880792      0.000000000     -1.200880848
H       -0.931880792      0.000000000     -1.200880848
*
```

得到如下输出：

```orca
---------------------------------
CARTESIAN NON-ADIABATIC COUPLINGS
           <GS|d/dx|ES>
        with built-in ETFs
---------------------------------

1   O   :   -0.071334028   -0.000001941    0.000003727
2   C   :   -0.362514525   -0.000000130   -0.000000776
3   H   :    0.217014763    0.000000003   -0.128968922
4   H   :    0.217014813   -0.000000002    0.128968939

Difference to translation invariance:
:    0.0001810232   -0.0000020693    0.0000029689

Norm of the NACs                   ...    0.5137724505
RMS NACs                           ...    0.1483133313
MAX NAC                            ...    0.3625145251
```

其中剩余的平移偏差仅来自 DFT 和 COSX 网格。

!!! note
    这些是推荐与任何动力学或锥形交叉优化一起使用的 NACs，
    否则移动体系的质心就已经会改变耦合！

<a id="sec:spectroscopyproperties.tddft.nacmes.numnacme"></a>
### 数值非绝热耦合矩阵元（Numerical non-adiabatic coupling matrix elements） 

CIS/TD-DFT 基态与激发态之间的数值非绝热耦合矩阵元
可以通过数值方式计算，方法是在主输入行设置 NumNACME 标志：

```orca
! NumNACME
```

ORCA 将以相同的代价同时计算给定 IROOT 的 NACMEs 和数值梯度。
请小心处理 SCF 选项和 GRID 大小，因为涉及到位移，
更多信息请查看 [essentialelements.numericalgradients](#sec:essentialelements.numericalgradients)。
所有关于步长等的选项都可以从 %NUMGRAD 更改。

这些目前在 RHF/RKS 和 UHF/UKS 中均已实现，但仅适用于 CIS/TDA 和 RPA/TD-DFT，
尚无多参考方法。对于后者，使用 $| X -Y \rangle$ 矢量的重叠
[Liu_HFNacme_2014](../../bibliography.md)。
