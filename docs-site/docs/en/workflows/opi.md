# ORCA Python Interface

With ORCA 6.1, we released an open-source ORCA Python Interface (OPI) supported by FACCTs. It is available on [GitHub](https://github.com/faccts/opi) and can also be installed via [PyPI](https://pypi.org/project/orca-pi/).

[![opi_logo_horizontal](../images/opi_logo_horizontal.svg)](../images/opi_logo_horizontal.svg)

The technical documentation, guides, and tutorials can be found at the [OPI Documentation pages](https://www.faccts.de/docs/opi/1.0/docs/).

> **Tip**
> OPI is designed as an open-source community project and therefore contributions from external developers are very welcome.
