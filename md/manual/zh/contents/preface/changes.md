# ORCA 6.1 亮点

基于去年随 ORCA 6.0 推出的大幅改进的基础设施，我们得以快速推进开发，从而能够向您呈献 ORCA 6.1。ORCA 6.1 带来了进一步的效率提升，以及一大批令我们振奋的新功能：

- 扩展了对高级从头算（ab initio）方法磁性质计算的支持
- 自动分片（auto fragmentation）：全自动分片算法
- 拉曼（Raman）强度的解析计算
- 简化的多尺度（multiscale）设置：自动生成 QM 区域和活性区域（active region）
- RESP 电荷：限制性静电势（restrained electrostatic potential）电荷
- GOAT 和 DOCKER 的更新
- 静电势（electrostatic potential）：通过 `orca_plot` 自动生成 ESP

关于 ORCA 6.1 的详细变更日志，请参阅[详细变更日志](/contents/appendix/detailedchangelog.md)。
