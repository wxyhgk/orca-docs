# 多尺度模型入门——QM/XTB ONIOM

让我们开始涉足多尺度计算（multiscale calculations）的世界。这里的"多尺度"是指我们将对体系的不同部分采用不同的理论水平/方法。

这些多尺度模型可用于多种问题：以较高水平处理蛋白质的活性位点、以较简单水平处理蛋白质的其余部分；以较高水平建模发色团、以较低水平处理周围显式溶剂；甚至将中等大小的体系分割成更小的部分以提高效率。

在 ORCA 中，有多种方法可以进行多尺度模拟，主要分为三大类：

1. 混合不同"量子力学"（Quantum Mechanical, QM）方法的 ONIOM 方法，
2. 将 QM 与依赖于预定义力场的"分子力学"（Molecular Mechanics, MM）方法相结合的 QM/MM 方法，以及
3. Crystal-QM/MM 方法：以高水平 QM 处理周期性晶体的一小部分（例如晶胞），并将其嵌入到大超胞模型的低水平模型中。

需要强调的是，我们的实现在所有情况下都以"QM 为中心"的视角为核心，也就是说，它面向熟悉 QM 方法的用户，本教程也是如此。

## 我们的第一个 ONIOM 单点计算

我们从一种非常简单的方法开始：QM/QM2 计算。这意味着我们将在同一体系的不同部分使用两种不同的 QM 水平。具体来说，我们从最简单的情况入手，使用 QM/XTB，将 Stefan Grimme 的 GFN2 方法（XTB2）[[Grimme2019]](../bib.md#grimme2019) 与常规的[密度泛函理论（Density functional theory, DFT）](../prop/single_point.md#dft)配合使用。

作为测试体系，我们将使用 S66 基准集中的 Peptide...Peptide 对 [[Hobza2011]](../bib.md#hobza2011)（结构取自[这里](http://www.begdb.org/index.php?action=oneMolecule&amp;state=show&amp;id=4127)）。它是由两个简单酰胺构成的复合物，用于模拟肽分子间的相互作用：

[![pep2](../images/pep2.png)](../images/pep2.png)

以仅计算[单点能](../prop/single_point.md#spen)为目标开始，你会看到在 ORCA 中使用 QM/XTB 非常简单。你所要做的只是准备好常规的 QM 输入文件，再加上 `!QM/XTB` 标志，并在 `%QMMM` 中列出应在较高 QM 水平下处理的原子。

## ONIOM 输出

现在，除了常规的 ORCA 输出之外，还有 QM/QM2 特有的部分：

```text
                     **************************
                     *    2-layered ONIOM     *
                     **************************
(...)
Multiscale model                       ... QM1/QM2
QM2 method                             ... XTB2
Coupling Scheme                        ... subtractive
Embedding Scheme                       ... electrostatic
(...)
Size of different subsystems (in atoms):
Size of QMMM System                    ... 24
Size of QM2 Subsystem                  ... 12
Size of QM1 Subsystem                  ... 12
(...)
```

关于 ONIOM 方法有不少打印内容，但这里重要的是：

> 1. *多尺度模型*为 *QM1/QM2*，其中 *QM2* 使用 *XTB2*
> 2. 默认的耦合方案是*减法（subtractive）*。这与最终能量的计算方式有关。
> 3. 默认的嵌入方案是*静电（electrostatic）*。这与两个 QM 体系如何进行静电相互作用有关。
> 4. 体系的完整大小为 24 个原子，每个子体系的大小为 12。

接下来是减法方案所必需的计算：使用 QM2 计算完整体系、使用 QM2 计算高水平区域（小体系）以及使用 QM1 计算高水平区域。首先打印的是两个 QM2 水平的计算：

### 选择合适的 QM 区域

这一误差实际上并非 ONIOM 流程本身所固有，而是源于*针对这一特定问题*时 QM 区域选择不当。由于我们最终要计算的是氢键断裂相关的能量（氢键是我们这里最强的结合点），更合理的选择是将直接参与结合的原子选为高水平区域：

[![pep2_qmmmregions_2](../images/pep2_qmmmregions_2.png)](../images/pep2_qmmmregions_2.png)

反映到输入文件上，只需稍微不同的输入：

```text
! QM/XTB revPBE D4 DEF2-TZVP PAL16
%QMMM QMATOMS {4:7 16:19} END END
%MAXCORE 3000
* XYZ 0 1
```

得到的结合能为 $E^{ONIOM}_{binding} = 8.41 \hspace{3pt} kcal/mol$，仅与参考值相差 $0.3 \hspace{3pt} kcal/mol$。

当然，这是一个相当小的例子，但同样的原则适用于更大的体系。只要区域选择得当，多尺度方法就能在误差仍然相对较小的情况下大幅加速计算！

| 方法 | $E_{binding}$ kcal/mol |
| --- | --- |
| 纯 DFT | 8.70 |
| 纯 XTB | 8.03 |
| 朴素 ONIOM | 10.25 |
| 合理的 ONIOM | 8.41 |
| 参考值 [[Hobza2011]](../bib.md#hobza2011) | 8.72 |

> **重要**
> 务必使所选的 QM 区域能够反映你想要研究的化学现象！

## 补充内容

下面是关于 ONIOM 或 QM/MM 方案的一些补充说明。Lili Cao 和 Ulf Ryde 的综述 [[Ryde2018]](../bib.md#ryde2018) 是一份很好的参考文献。

### 什么是"减法 ONIOM（subtractive ONIOM）"？

计算 QM/MM 或 ONIOM 能量有两种主要方法：加法（additive）与减法（subtractive）。在减法方案中，能量按下式计算：

$$
E^{sub}_{QM1/QM2} = E_1^{QM1} + E_{12}^{QM2} - E_1^{QM2}
$$

其中下标表示方法所应用的体系：1 对应高水平区域，2 对应低水平区域，12 对应完整体系。减法方案可用于 QM1/QM2 方法和 QM/MM 方法。

在加法方案中（仅可用于 QM/MM），能量按下式计算：

$$
E^{add}_{QM/MM} = E_1^{QM} + E_{2}^{MM} + E_{1/2}^{QM/MM}
$$

其中最后一项对应于体系 1 和 2 之间的相互作用能项。

在 ORCA 中，ONIOM 方法默认采用减法方案，而 QM/MM 默认采用加法方案。

### 什么是"静电嵌入（electrostatic embedding）"？

当把一个大体系分割成两个或更多个小体系时，我们需要决定如何恰当地包含它们之间的相互作用。计算高水平与低水平区域之间静电相互作用有两种不同的方案："机械嵌入（mechanical embedding）"和"静电嵌入（electrostatic embedding）"。

在较简单的**机械嵌入**方案中，两个体系的静电相互作用仅用较低水平的 QM2 或 MM 方法来考虑，而不考虑低水平区域在较高水平 QM 方法下对高水平区域的极化作用。

在**静电嵌入**方案（ORCA 的默认方案）中，高水平计算是在低水平区域电荷存在的条件下进行的。第二种方法更准确，因为它能让高水平区域在高水平计算中于低水平区域存在的情况下发生极化。
