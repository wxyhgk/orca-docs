# 紫外-可见光谱（UV/Vis）

预测紫外-可见光谱（UV/Vis spectrum），本质上就是预测体系的电子激发态、它们的能量以及它们之间跃迁的概率。

在 ORCA 中，有几种方法可以以较高或较低的精度计算激发态性质，但这里我们只讨论其中两种：较简单且广泛使用的 TD-DFT，它在速度与精度之间有很好的折衷；以及较新的 STEOM-DLPNO-CCSD，它更接近激发态方法的高端水平。

## 示例：偶氮苯的 E/Z 异构体

为了把这个相当抽象的主题变得更具体，我们将尝试模拟一个偶氮苯衍生物的实验结果 [[Temps2009]](../bib.md#temps2009)：

[![eq_color](../images/eq_color.png)](../images/eq_color.png)

*图：偶氮苯衍生物的 E- 和 Z-异构体及其在实验中观察到的颜色。*

事实证明 E 和 Z 异构体具有不同的颜色——一个是黄色，另一个是红色——作者将其归因于低能谱带的变化，该谱带被指认为 $n-\pi^*$ 跃迁。让我们看看如何从第一性原理预测这些结果。

### TD-DFT

含时密度泛函理论（time-dependent density functional theory, TD-DFT）是预测紫外-可见光谱最常用的方法之一，
因为它相当简单且计算量不太大。在 ORCA 中的使用很简单，例如选择 CAM-B3LYP 泛函和三 zeta 基组：

```text
!CAM-B3LYP DEF2-TZVP CPCM(HEXANE)

%TDDFT
   NROOTS   30
END

*XYZFILE 0 1 E-isomer-optimized.xyz
```

`%TDDFT` 会自动请求预测光谱所需的激发态计算，NROOTS 标志控制你想要包含的激发态数目。

这里我们还使用 CPCM 作为基态和激发态的[溶剂化模型](../prop/cpcm.md)来模拟实验中使用的正己烷，
对于激发态这意味着默认使用 LR-CPCM 模型。常规 SCF 之后，会打印出 TD-DFT 表头：

### 绘制计算光谱

为了近似实验光谱，我们可以把这些谱线与
高斯函数进行卷积，把它们变成谱带。这可以很容易地用
[ChimeraX](../first_steps/GUI.md) 配合 SEQCROW 插件来完成。在 ChimeraX 中打开输出文件，
然后导航到 `Tools` → `Quantum Chemistry` → `UV/Vis Spectrum`。
在 UV/Vis Spectrum 窗口中，你现在可以从相应的下拉菜单中选择 `energy for weighting: electronic`，相应的图将在 `plot` 下可视化。

[![uvvis-chimerax](../images/uvvis-chimerax.png)](../images/uvvis-chimerax.png)

*图：ChimeraX 的 UV/Vis 光谱面板。*

或者，我们可以使用 `orca_mapspc` 实用程序从输出文件生成可绘图的数据。在本例中我们可以使用如下命令行调用：

orca_mapspc orca.out ABS -x002 -x106 -eV -n400 -w0.5

这将生成从 2 到 6 eV 的 400 个数据点，高斯展宽为 0.5 eV。现在我们可以用任何绘图程序绘制数据，例如 `gnuplot`。

[![uvvis](../images/uvvis.png)](../images/uvvis.png)

*图：在 CAM-B3LYP[CPCM(HEXANE)]/def2-TZVP 水平上计算的光谱。*

### 激发态分析

偶氮苯谱带的常见指认是：低能峰对应
于 $S_1$ 态，具有 $n\rightarrow\pi^*$ 特征，而能量较高的 $S_2$ 是
$\pi\rightarrow\pi^*$ 态——这对异构化过程有重要影响。

我们可以利用计算结果来帮助完成这项复杂任务，方法是检查
激发态的组成。如前所述，TD-DFT 输出中打印出
第一激发态（E 异构体）由以下组成：

```text
STATE  1:  E=   0.093509 au      2.545 eV    20522.9 cm**-1 <S**2> =   0.000000 Mult 1
    50a ->  55a  :     0.138453 (c= -0.37209218)
    54a ->  55a  :     0.799904 (c= -0.89437354)
    54a ->  59a  :     0.027597 (c= -0.16612343)
```

这意味着 $S_1$ 态约有 80% 由 HOMO 到 LUMO 的跃迁组成，即从轨道 54 到轨道 55。

如果你在主输入中使用 `LARGEPRINT` 运行计算，就可以通过
直接在 [Avogadro 2](../first_steps/GUI.md) 或 [ChimeraX](../first_steps/GUI.md) 中打开 `basename.out` 文件来可视化这些轨道，它们是：

[![states-mos](../images/states-mos.png)](../images/states-mos.png)

如你所见，HOMO 是一个 $n$ 型分子轨道，主要位于氮原子的孤对电子上，
而 LUMO 是一个 $\pi^*$ 轨道，主要在 N=N 键周围，从而
证实了所建议的指认。

我们还打印了 $S_2$ 的主要成分，它是 89% 的 HOMO-1 到 LUMO 跃迁。从上面的图中
也可以看出，HOMO-1 现在更像一个常规的 $\pi$ 轨道，因此
$\pi\rightarrow\pi^*$ 的指认似乎是一个很好的假设。不过，现在我们甚至有了
它来自环轨道到 N=N 反键轨道这一信息。

> **重要**
> Avogadro 2 和 ChimeraX 从 1 开始对轨道计数，但 ORCA 从 0 开始计数。所以 ORCA 中的轨道 54 在 Avogadro 2 和 ChimeraX 中将是轨道 55，依此类推！

### 自然跃迁轨道（NTO）

另一种研究激发态性质的方法是查看每次
跃迁的自然跃迁轨道（natural transition orbitals, NTO）[[Martin2003]](../bib.md#martin2003)。它们是分子轨道更紧凑的形式，
有助于解释更复杂的情况。以 E 异构体的激发态 13 为例：

```text
STATE 11:  E=   0.231920 au      6.311 eV    50900.7 cm**-1 <S**2> =   0.000000 Mult 1
    49a ->  55a  :     0.041027 (c=  0.20255160)
    50a ->  56a  :     0.175321 (c= -0.41871391)
    51a ->  58a  :     0.117541 (c= -0.34284283)
    52a ->  59a  :     0.078697 (c=  0.28052958)
    53a ->  57a  :     0.189575 (c=  0.43540185)
    54a ->  56a  :     0.193178 (c=  0.43951980)
    54a ->  59a  :     0.154964 (c=  0.39365511)
```

这里至少涉及七个较大的跃迁，梳理起来可能相当令人困惑。
为了用 NTO 来评估激发态，可以在 `TDDFT` 块中通过 `DONTO TRUE`
请求它们：

```text
!CAM-B3LYP DEF2-TZVP CPCM(HEXANE)

%TDDFT
   NROOTS   30
   DONTO    TRUE
END

*XYZFILE 0 1 E-isomer-optimized.xyz
```

相应的 NTO 现在被打印到输出文件中：

```text
------------------------------------------

------------------------------------------

Making the (pseudo)densities                       ... done
Solving eigenvalue problem for the occupied space  ... done
Solving eigenvalue problem for the virtual space   ... done
Natural Transition Orbitals were saved in orca.s11.nto
Threshold for printing occupation numbers 0.001000

 E=   0.231920 au      6.311 eV    50900.7 cm**-1
    54a ->  55a  : n=  0.56085719
    53a ->  56a  : n=  0.20022822
    52a ->  57a  : n=  0.11450247
    51a ->  58a  : n=  0.08591581
    50a ->  59a  : n=  0.03500731
```

$S_{11}$ 现在用两个主导跃迁来描述。这些 NTO 保存在
名为 `basename.s11.nto` 的文件中，可以用 **orca_plot** 工具绘制：

```text

```

这里我们使用选项 `2 - Enter no of orbital to plot` 来选择相应的轨道（53-56），使用 `5 - Select output file format` 来
选择 `7 -   3D   Gaussian cube` 作为输出格式。`11 - Generate the plot` 现在将创建 `.cube` 文件来绘制 NTO。

为轨道 53-56 生成 .cube 文件后，可以用 ChimeraX 绘制它们。
为此，只需将结构 .xyz 文件和 .cube 文件拖放到 ChimeraX 窗口中即可。

它们是一个主导的 $n\rightarrow\pi^*$ 跃迁和一个次要的进入芳香环的 $\pi\rightarrow\pi^*$ 跃迁。

### STEOM-DLPNO-CCSD

如上所示，TD-DFT 在许多情况下可以成功预测激发态，
但人们无法**先验**地知道某个泛函是否有效，而且不同的
泛函必然会给出不同的结果。

为了避免在泛函之间的这种试错，*从头算*（ab initio）无经验参数方法
有时是更好的选择。在 ORCA 中，这些方法有很多可用，但为了
简洁起见，我们在这里展示一种精度非常好、同时计算成本
仍可承受的方法：相似变换运动方程 CCSD（Similarity Transformed Equation of Motion CCSD，STEOM-CCSD）。

STEOM-CCSD 是一种在激发态计算中也包含[相关能](../prop/corren.md#corren)的方法，从而提高了预测质量 [[Iszak2019a]](../bib.md#iszak2019a)。它本身是一种很重的方法，计算量非常大，但 ORCA 团队最近开发了它的 [DLPNO 方案](../prop/corren.md#dlpno)版本（DLPNO-STEOM），其标度行为要好得多，而且不比 TD-DFT 贵多少 [[Iszak2019b]](../bib.md#iszak2019b)。

要使用它，只需以某种方式优化好几何结构并运行：

```text
!STEOM-DLPNO-CCSD def2-TZVP def2-TZVP/C RIJCOSX CPCM(HEXANE)

%MDCI
   NROOTS  15
   DOSOLV  TRUE
END

*XYZFILE 0 1 E-isomer-optimized.xyz
```

与其他使用 RI 的 DLPNO 或相关方法一样，计算需要 /C 基组。
我们还为基态和激发态添加了 CPCM 校正，后者在这里通过
在控制这些计算的 `%MDCI` 块中设置 `DOSOLV TRUE` 来调用。

> **注意**
> 与其他 CC 方法一样，可能需要大量内存。另外，请确保使用足够大的基组，至少要达到 def2-TZVP 的规模，以获得一致的结果。

打印出的输出比 TD-DFT 的大得多，因为完成整个计算需要更多的步骤。总结来说，所做的是：

> 1. 首先进行常规的 DLPNO-CCSD 计算。
> 2. 然后是一个简单的 CIS 计算，这对于缩减活性空间是必要的。
> 3. 然后分别进行 DLPNO-IP-EOM 和 DLPNO-EA-EOM 计算。
> 4. 变换若干积分。

最后，STEOM-CCSD 步骤开始：

```text
---------------------------------------------------
           RHF STEOM-CCSD CALCULATION
---------------------------------------------------

Multiplicity                               ... singlet
Solver                                     ... Davidson
Convergence check                          ... for each root separately
Convergence threshold                      ... 1.00E-05
Root homing                                ... on
Preconditioning update                     ... CIS
Reduced space size (times number of roots) ... 40
Number of roots in the CIS initial guess   ... 600
Number of roots to be optimized            ... 15
Number of amplitudes to be optimized       ... 20007
[...]
```

> 即使预测光谱与实验吻合，计算仍然没有*精确*重现光吸收过程中发生的事情。完整实验光谱必然还包括振动分辨，甚至可能还有振动电子耦合（vibronic coupling）。这可以通过 `ORCA_ESD` 模块包含进来。
