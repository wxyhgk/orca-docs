# 自动对接（DOCKER）

寻找各种分子之间合适的相互作用模式可能是一项繁琐的工作，通常依赖于化学直觉。DOCKER 是一种能量驱动的算法，可自动对接原子和分子结构，以形成相遇复合物和聚集体。

> **注意**
> 请注意，DOCKER 算法目前尚未完全并行化，因此限制了可处理体系的规模。完全并行化将在未来的 ORCA 版本中加入。

DOCKER 与 Grimme 高效的 GFNn-xTB 方法（GFN1-xTB、GFN2-xTB、GFN0-xTB、GFN-FF）相结合，可以通过简单输入轻松调用：

```text
!DOCKER(GFN2-XTB)

%DOCKER
     GUEST "guest.xyz"
END

*XYZFILE 0 1 host.xyz
```

DOCKER 的详细功能可以通过 `%DOCKER` 块控制，更多信息请参见 [ORCA 手册](https://www.faccts.de/docs/orca/6.1/manual)。

## 示例 1：尿嘧啶的二聚化

作为一个简单示例，我们可以用 DOCKER 为尿嘧啶二聚体创建结构候选。
所用的示例输入如下：

```text
! XTB PAL8

%DOCKER
    GUEST "uracil.xyz"
END

*XYZFILE 0 1 uracil.xyz
```

## 示例 2：环辛醇与 $\beta$-CD 的对接

在本例中，我们将把环辛醇对接到 $\beta$-环糊精上。对于非常大的分子，使用 GFN2-xTB 可能代价过高。
因此，我们在本例中示例性地使用 GFN-FF 力场。所采用的输入如下：

```text
! XTBFF

%DOCKER
    GUEST "cyclooctanol.xyz"
END

*XYZFILE 0 1 cyclodextrin.xyz
```

DOCKER 给出的主客体复合物中，环辛醇位于环糊精的中心，是能量上最有利的结构。其他醇位于环糊精外缘的相互作用模式也包含在 `orca.docker.struc1.allopt.xyz` 文件中。
