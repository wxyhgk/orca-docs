# 色散校正

传统密度泛函理论（以及 Hartree-Fock）一个众所周知的缺点是缺乏对长程相关效应的描述。
其中包括伦敦色散（London dispersion），即范德华相互作用中的吸引成分。不过，目前已有若干
成熟的色散校正（dispersion correction）可以大幅修正这一缺陷。在 ORCA 中提供了多种选择，
包括 Grimme 的 D3 [[Goerigk2011]](../bib.md#goerigk2011) 和更新的 D4 [[Grimme2017]](../bib.md#grimme2017) 校正，
以及 VV10 的非局域变体（NL，[[Grimme2011b]](../bib.md#grimme2011b)）。

最常见的做法是在 SCF 之后将这些校正作为对所得能量的修正项加入。只需相应的简单关键词即可轻松调用这些校正：

```text
!B3LYP D4 DEF2-TZVP
```

或

```text
!B3LYP NL DEF2-TZVP
```

对于 NL，还提供了自洽（self-consistent）处理方式，可通过以下方式调用：

```text
!B3LYP SCNL DEF2-TZVP
```

由于缺乏伦敦色散是传统 DFT 和 Hartree-Fock 一个非常系统性的缺陷，我们一般建议在使用此类方法进行任何几何优化或能量计算时都加上这类校正。

> **注意**
> 由于这些校正具有半经验性质，必须有与所选泛函匹配的参数。如果默认没有提供这些参数，你可以按照
> [ORCA 手册](https://www.faccts.de/docs/orca/6.0/manual)中的说明在 ORCA 输入文件中提供或调整它们。

## 示例：苯二聚体

让我们测试伦敦色散对苯二聚体几何结构的影响。为此，我们在 B3LYP/def2-TZVP
水平下优化几何结构，一次不加校正：

```text
!B3LYP DEF2-TZVP OPT
* XYZFILE 0 1 benzene-dimer.xyz
```

另一次启用 D4 色散校正：

```text
!B3LYP D4 DEF2-TZVP OPT
* XYZFILE 0 1 benzene-dimer.xyz
```

最后，我们将这些结构与在相关方法 CCSD(T)/cc-pVTZ 水平下得到的参考几何结构（[[Xantheas2022]](../bib.md#xantheas2022)）进行比较，该方法本身就涵盖了色散效应。

[![benzene-dimer](../images/benzene-dimer.png)](../images/benzene-dimer.png)

我们可以清楚地看到，只有包含色散校正的计算才与高水平方法符合得较好。这凸显了即便对于这样小的体系，色散校正也极为重要。由于这些色散校正几乎不带来任何额外的计算开销，我们强烈建议始终使用色散校正。
